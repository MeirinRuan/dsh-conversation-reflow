# Conversation Reflow

English | [中文](README.zh.md)

Keep conversation text and Markdown table cells within the width available between sidebars. The plugin preserves font size and retains scrolling for content that still needs it.

The plugin uses DSH extension points and leaves with its bundle when disabled. It adds no tools, model prompts, external requests, or conversation records.
